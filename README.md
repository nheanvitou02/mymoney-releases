## ✨ Key Features

- **100% Offline & Local-First:** All financial data stays strictly on your device inside an encrypted SQLite database. Zero cloud accounts, zero tracking, and zero data leaves your phone.
- **Dual-Currency Accounting (USD & KHR):** Full native dual-currency engine. Input in US Dollars ($) or Khmer Riels (៛) with configurable exchange rates (default 4,100 KHR per 1 USD) and exact integer-based financial calculations.
- **Cambodia Timezone Standardized:** Calendar day boundaries and financial summaries are anchored strictly to Cambodia Standard Time (`Asia/Phnom_Penh`, UTC+7) with backdated transaction support.
- **Quick Transaction Entry:** Minimal-tap transaction recording with 14 pre-loaded bilingual categories, custom notes, and calendar date selection.
- **Visual Analytics & Reports:** Dynamic daily income/expense trends, ranked category expense breakdowns with interactive donut charts, and monthly comparisons.
- **Savings Goals & Contributions:** Set targets in USD or KHR, track accumulated deposits with animated progress bars, and archive completed goals.
- **Complete Data Sovereignty:** Export full database backups in JSON format, restore atomically with conflict resolution, and export clean CSV spreadsheets with UTF-8 BOM for Microsoft Excel.
- **Bilingual Interface:** Instant seamless switching between Khmer (`ខ្មែរ`) and English (`EN`).
- **Dynamic Appearance:** Modern "Soft Emerald" design system supporting Light, Dark, and System (follow device OS night mode) themes.
