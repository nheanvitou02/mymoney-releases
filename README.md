### 💡 អំពី MyMoney (About MyMoney)

#### MyMoney គឺជាអ្វី?
**MyMoney (លុយខ្ញុំ)** គឺជាកម្មវិធីទូរស័ព្ទដៃសម្រាប់តាមដាន និងគ្រប់គ្រងប្រាក់កាសផ្ទាល់ខ្លួនប្រចាំថ្ងៃ។ កម្មវិធីនេះដំណើរការនៅលើទូរស័ព្ទ Android ដោយរក្សាទុកទិន្នន័យទាំងអស់នៅលើទូរស័ព្ទផ្ទាល់របស់អ្នក (Local SQLite Database) ដោយមិនបញ្ជូនទិន្នន័យចេញក្រៅ ឬតភ្ជាប់ទៅកាន់ Cloud Server ណាមួយឡើយ។

#### គោលបំណងរបស់កម្មវិធី
1. **ភាពងាយស្រួល និងរហ័ស:** កត់ត្រាចំណូល និងចំណាយបានលឿនដោយចុចត្រឹមតែ ២ ទៅ ៣ ដងប៉ុណ្ណោះ។
2. **គាំទ្រសេដ្ឋកិច្ចកម្ពុជា:** គាំទ្ររូបិយប័ណ្ណពីរ (ដុល្លារ $ និង រៀល ៛) ដោយមានអត្រាប្តូរប្រាក់ដែលអាចកំណត់បាន (កំណត់លំនាំដើម ៤,១០០ រៀល/ដុល្លារ) និងការគណនាគណិតវិទ្យាជាក់លាក់ដោយគ្មានបញ្ហាទសភាគ។
3. **ឯកជនភាព និងសុវត្ថិភាពដាច់ខាត:** មិនទាមទារបង្កើតគណនី (No Login) មិនទាមទារលេខទូរស័ព្ទ ឬអ៊ីមែល និងមិនភ្ជាប់ទៅធនាគារណាមួយឡើយ។ ទិន្នន័យទាំងអស់ជាកម្មសិទ្ធិរបស់អ្នក ១០០%។
4. **កាលបរិច្ឆេទ និងម៉ោងកម្ពុជា:** ម៉ោង និងថ្ងៃត្រូវបានកំណត់តាមម៉ោងស្ដង់ដារកម្ពុជា (`Asia/Phnom_Penh`, UTC+7) ព្រមទាំងអាចជ្រើសរើសថ្ងៃប្រតិបត្តិការថយក្រោយបានយ៉ាងងាយស្រួល។

### ✨ មុខងារសំខាន់ៗដែលមានក្នុង v1.0.0 (Key Features)

- **ក្រៅបណ្តាញ ១០០% (100% Offline Local-First):** ទិន្នន័យត្រូវបានរក្សាទុកក្នុងទូរស័ព្ទរបស់អ្នកដោយប្រើ Expo SQLite (WAL mode) មិនត្រូវការអ៊ីនធឺណិត និងគ្មានការបញ្ជូនទិន្នន័យចេញក្រៅ។
- **ប្រព័ន្ធរូបិយប័ណ្ណពីរ (USD & KHR):** កត់ត្រាជាដុល្លារ ឬរៀលដោយឡែកពីគ្នា ព្រមទាំងបម្លែង និងបង្ហាញសមតុល្យរួមប្រកបដោយភាពសុក្រឹតតាមអត្រាប្តូរប្រាក់ដែលអ្នកកំណត់។
- **ផ្ទាំងគ្រប់គ្រងទិន្នន័យ (Dashboard):** បង្ហាញសមតុល្យសរុប ចំណូល ចំណាយប្រចាំខែ ក្រាហ្វិកចំណូល-ចំណាយប្រចាំថ្ងៃ និងប្រតិបត្តិការចុងក្រោយ ៥ យ៉ាងច្បាស់លាស់។
- **ការកត់ត្រា និងស្វែងរកប្រតិបត្តិការ (Transactions & Search):** បង្អួចបញ្ចូលទិន្នន័យរហ័ស ប្រភេទចំណូល-ចំណាយលំនាំដើមចំនួន ១៤ ព្រមទាំងមុខងារស្វែងរក និងច្រោះតាមប្រភេទ។
- **ការការពារប្រភេទចំណាយ (Category Safety Guard):** ការពារមិនឱ្យលុបប្រភេទណាដែលមានប្រតិបត្តិការជាប់ពាក់ព័ន្ធឡើយ និងមានមុខងារផ្ទេរប្រតិបត្តិការទៅប្រភេទថ្មីមុនពេលលុប។
- **ការកំណត់កាលបរិច្ឆេទប្រតិបត្តិការ (DatePicker):** អាចជ្រើសរើសថ្ងៃប្រតិបត្តិការថយក្រោយ (ថ្ងៃនេះ, ម្សិលមិញ ឬជ្រើសតាមប្រតិទិន) ដោយបដិសេធកាលបរិច្ឆេទអនាគត។
- **គោលដៅសន្សំប្រាក់ (Savings Goals):** បង្កើតគោលដៅសន្សំ កំណត់រូបិយប័ណ្ណ និងកត់ត្រាការដាក់ប្រាក់សន្សំ ដោយមានរបារបង្ហាញភាគរយរីកចម្រើនយ៉ាងរលូន។
- **របាយការណ៍ និងការវិភាគ (Reports & Analytics):** ជ្រើសរើសចន្លោះកាលបរិច្ឆេទបត់បែន (ខែនេះ, ខែមុន, ៦ខែ, ឆ្នាំនេះ, ឬកំណត់ដោយខ្លួនឯង) ជាមួយតារាង Donut Chart បង្ហាញភាគរយតាមប្រភេទ និងក្រាហ្វិកប្រៀបធៀបរយៈពេល ៦ ខែ។
- **ការនាំចេញ និងស្តារទិន្នន័យ (Backup & Restore):** នាំចេញឯកសារ JSON Backup ពេញលេញ នាំចូលស្តារទិន្នន័យវិញដោយសុវត្ថិភាព (Replace ឬ Merge) និងនាំចេញជា CSV (UTF-8 BOM) សម្រាប់បើកមើលលើ Microsoft Excel។
- **ភាសាពីរ (Khmer & English):** ប្តូររវាងភាសាខ្មែរ និងអង់គ្លេសបានភ្លាមៗគ្រប់ទំព័រ។
- **ស្បែកកម្មវិធី Soft Emerald (Themes):** គាំទ្ររចនាប័ទ្មពណ៌ពន្លឺ (Light), ពណ៌ងងឹត (Dark Mode) និងសម្របតាមប្រព័ន្ធទូរស័ព្ទ (System Mode)។

### 💡 About MyMoney

#### What is MyMoney?
**MyMoney (លុយខ្ញុំ)** is a local-first, offline personal finance mobile application tailored specifically for Cambodian users. It operates exclusively on Android devices, persisting all financial data inside the device's local application sandbox (Expo SQLite) without external cloud synchronization or remote server transmission.

#### Purpose of the Application
1. **Effortless & Fast Entry:** Record income and expenses in just 2 to 3 taps.
2. **Dual-Currency Support:** Native dual-currency engine supporting US Dollars ($) and Khmer Riels (៛) with configurable exchange rates (default: 4,100 KHR/USD) and integer minor-unit arithmetic eliminating floating-point errors.
3. **Absolute Data Privacy:** No login, no accounts, no phone numbers, no tracking, and no external banking connections. All data remains 100% on-device.
4. **Cambodia-Centric Design:** Timezone boundaries standardized to `Asia/Phnom_Penh` (UTC+7) with interactive calendar date selection supporting historical backdating.

---

### ✨ Key Features in v1.0.0

- **100% Offline & Local-First:** All financial records are stored strictly on-device in SQLite (`mymoney.db`) with WAL journal mode and foreign key enforcement.
- **Dual-Currency Precision Math:** Integer arithmetic (cents for USD, riels for KHR) with runtime currency conversion and configurable rounding modes (`EXACT` and `CASH_100`).
- **Interactive Dashboard:** Dynamic monthly balance summary, daily income/expense bar charts, recent transactions, and month-by-month navigation.
- **Transactions & Search:** Quick Add bottom sheet, 14 bilingual system categories, real-time keyword search, and filter pills (`All`, `Income`, `Expense`).
- **Category Deletion Safety Guard:** Prevents transaction loss by blocking deletion of referenced categories, supporting atomic reassignment before removal.
- **Transaction Date Picker:** Supports backdating transactions (`Today`, `Yesterday`, or interactive calendar picker) while strictly rejecting future dates.
- **Savings Goals & Contributions:** Dedicated goals tracking with locked currency, atomic progress recalculation, and smooth animated progress bars.
- **Reports & Analytics:** Flexible date presets (This Month, Last Month, 6 Months, This Year, Custom Range), ranked category lists, donut breakdown charts, and 6-month trends.
- **Data Backup & Portability:** Atomic full JSON backup export and restore (supporting `REPLACE` and `MERGE` modes with rollback protection), and UTF-8 BOM CSV export for Microsoft Excel.
- **Bilingual Interface:** Instant runtime switching between Khmer (`ខ្មែរ`) and English (`EN`).
- **Soft Emerald Theme:** Calm, modern design language supporting Light, Dark (`#0B1220`), and System (OS night mode) appearance.
